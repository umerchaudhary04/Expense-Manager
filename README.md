# Expense Manager

A clean, intuitive, and robust Expense Management application built with Flutter. **Expense** helps you track your daily spending, manage custom categories and tags, and keep an eye on your budget directly in PKR (Pakistani Rupee).

## 📱 Features

- **Track Expenses:** Easily add, edit, or delete expenses with details like payee, amount, date, and notes.
- **Custom Categories & Tags:** Create and manage your own custom categories and tags to organize your spending your way.
- **Two Views:**
  - *By Date:* View your expenses in a chronological list.
  - *By Category:* View your total spending grouped by different categories.
- **Swipe to Delete:** Intuitive UI allowing users to easily delete an expense by swiping a card.
- **Local Persistence:** All data is saved directly to your device's local storage. Your expenses will never be lost when you close the app.
- **Currency:** Displays all amounts formatted in PKR.

## 🛠 Tech Stack

- **Framework:** Flutter / Dart
- **State Management:** Provider
- **Local Storage:** `localstorage` package
- **Formatting:** `intl` package (for Dates & Currency)
- **Data Aggregation:** `collection` package
